# 🐾 Sistema de Gestión Web - Pet Shop "Hola Humano"

### 📋 Descripción del Proyecto
Aplicación web Full Stack desarrollada como trabajo final integrador. Simula el ecosistema digital de una tienda de mascotas, con foco en la gestión de usuarios, productos y control de accesos.

### 💻 Funcionalidades Clave
* **Seguridad y Accesibilidad:**
    * Sistema de **Login y Registro** con validación de credenciales.
    * **Roles de Usuario:** Diferenciación estricta entre *Cliente* (vista pública) y *Administrador* (acceso total).
* **Panel de Administrador:**
    * **CRUD Completo:** Alta, Baja y Modificación de Productos y Usuarios.
    * **Búsqueda Avanzada:** Localización de usuarios por DNI o ID.
    * **Gestión de Contenido:** Administración de consejos y blog.
* **Experiencia de Usuario:**
    * Catálogo filtrado por categorías (Perros, Gatos, Otros).
    * Interfaz intuitiva y responsive.
* **Validaciones de datos y manejo básico de errores en formularios y flujos de administración.**

### 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Python 3.
* **Framework Web:** Flask.
* **Base de Datos:** MySQL (conector `flask_mysqldb`).
* **Frontend:** HTML5, CSS3, Bootstrap, Jinja2.
* **Herramientas:** Visual Studio Code, XAMPP.
